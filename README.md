# VYRO Android Starter

This is the first working UI prototype for the VYRO video editor.

Included:
- Animated VYRO splash screen
- Home screen
- New Project button
- Video editor UI prototype
- Timeline mockup
- Overlay, split, effects, filters and text entry points

Open this folder in Android Studio and build/run it on an Android phone or emulator.

This version is a UI prototype. Real video trimming, exporting, background removal and media processing should be added in the next development stages.
